Need help?

Which browser?

Use Chrome or Edge on a Mac, Windows PC or Linux computer. iPhone, iPad and Safari don’t support this USB installation flow.

How do I install?

Connect one board with a USB data cable. Click its matching install button, choose the USB serial port, then choose Install and confirm. Keep it connected until the success message appears. Close the dialog, unplug it and label it A or B before installing the other board. The two boards look identical, so the page cannot identify their roles automatically.

No board in the list?

Try a different data cable or USB port and close other apps using the board. A USB driver may be needed: CP210x or CH340, depending on your board’s USB chip.

Connection failed?

Hold BOOT as you start the installation, then release it once the chip is detected or installation begins. If needed, press EN/reset and try again. Use original ESP32-WROOM-32 boards; S2, S3 and C3 are incompatible.

What works so far?

This is experimental firmware. Physical iPhone and Tesla compatibility and reliable reconnection still need testing. Calls, music passthrough and WhatsApp replies are not supported. A successful installation confirms the firmware was written, not that it works with your car. Current limitations · Full setup guide

Hardware testing is still pending. Follow the setup guide for your first parked-car test.
