Help

Which browser?

Use Chrome or Edge on a Mac, Windows PC or Linux computer. iPhone, iPad and Safari don’t support USB installation.

Installing both boards

Connect only one board at a time. Select A for the iPhone board or B for the Tesla board. Click Install, choose its USB port, and confirm. Wait for the success message, close the dialog and unplug the board. Label it A or B, then repeat with the other board. Start the Bluetooth setup with Board B.

No board in the USB list?

Try a different data cable or USB port and close other apps using the board. Some boards need a USB driver: CP210x or CH340, depending on the USB chip.

Connection failed?

Hold BOOT as you start installation. Release it once the chip is detected or installation begins. If needed, press EN/reset and try again. This firmware requires an original ESP32-WROOM-32; S2, S3 and C3 boards are incompatible.

Prototype status

The firmware has not been tested on physical boards with an iPhone and Tesla yet. Reconnection also needs testing. Calls, music passthrough and WhatsApp replies are not supported. Known limitations · Setup guide
