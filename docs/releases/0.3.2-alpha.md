# DashBridge 0.3.2-alpha

Released: 2026-09-21

## What was verified

Board B was tested in a Tesla with **DashBridge B** selected as the Priority
Device and **Sync Messages** enabled. After the vehicle woke, it automatically
reconnected the hands-free calling and message profiles. New-message
notifications were ready without manually reconnecting the device.

## Setup requirements

- Install the matching `0.3.2-alpha` images on Board A and Board B.
- In the Tesla Bluetooth settings, set DashBridge B as the Priority Device.
- Enable Sync Messages for DashBridge B.
- Follow the [Bluetooth and wiring guide](../SETUP.md).

## Current limits

- The complete two-board iPhone call and audio path still needs an end-to-end
  vehicle test.
- Music, contact sync and outgoing message replies are not included in this
  release.

## Image identities

- Board A: `0.3.2-alpha+93fcd52cc2b3`
- Board B: `0.3.2-alpha+fe2ca23d30a7`

The suffix identifies the exact source used for each board image. The installer
shows the public release name and verifies the exact image identity before it
enables installation.
