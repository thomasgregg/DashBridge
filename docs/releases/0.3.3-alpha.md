# DashBridge 0.3.3-alpha

Released: 2026-09-21

This release adds call-audio diagnostics and clearer Bluetooth names. It is an
experimental release with **unresolved robotic call audio and unclear microphone
audio**. It is not a verified everyday replacement for direct iPhone calls.

## Changes

- Board A appears as **Dash Calls** and **Dash Messages** on iPhone; Board B as
  **Dash Tesla** on the car.
- iPhone notification discovery includes the ANCS/HID advertisement that enabled
  the notification-sharing prompt in the observed iOS 27 setup, without an extra app.
- Both Bluetooth sides support 16 kHz mSBC, with filtered 8 kHz CVSD fallback.
- Audio buffer draining and UART receive timing were corrected. The audio UART
  runs at 460800 baud, with CRC, sequence-gap and UART error counters.
- Either USB console can inspect both boards' audio and Bluetooth packet counters.
- Per-side quiet 1 kHz test tone and attenuated voice loopback can be selected
  during an active call. Tests default off, stop after 60 seconds or audio
  disconnection, and can be stopped with `audio off`.

## Evidence and limits

Both ESP32 roles compile with the pinned ESP-IDF **v5.5.5**. Sanitizer tests cover
notification handling, call controls, audio transport, tone timing, loopback,
timeouts and diagnostic command routing. Installer checks verify exact source,
image identity and binary checksums.

On the development builds, WhatsApp text reached Tesla through both boards,
iPhone calls and notification sharing reconnected after updates, and answered
FaceTime Audio calls negotiated mSBC on both links. Audio was still bad after the
captured wired transport showed no packet gaps, CRC failures or UART errors.
The diagnostic pair was installed and the remote stop command acknowledged.
**Tone/loopback listening tests and a new Bluetooth-error capture are pending.**
The release-number change rebuilds the same firmware logic; these exact release
images have not been flashed or listened to on hardware.

Music forwarding, media controls, contacts and message replies are not implemented.
Fixing call audio does not provide Bluetooth music. Daily reliability and all call
controls have not been fully verified. Hardware and radio causes remain possible.

## Setup and tests

Install both roles, wire the five connections in the [setup guide](../CALL_RELAY.md),
pair Dash Calls and Dash Messages with iPhone, and enable Share System Notifications.
On Tesla, connect Dash Tesla and enable Sync Messages. Use it as Priority Device
for the observed Tesla-owned wake reconnect path. Selecting the bridge replaces
the iPhone's direct phone/audio connection; the phone key is separate.

Follow the [audio isolation test guide](../AUDIO_ISOLATION_TESTS.md) one test at a
time. Start with an answered call and low speaker volume for loopback.
