# DashBridge 0.4.1-alpha

This prerelease adds a USB setup and connection-check screen to the two-board
0.4.0-alpha prototype. It is **not a verified daily-use adapter**. The
[0.4.0-alpha release notes](0.4.0-alpha.md) describe the call, music,
notification-history, and phonebook implementation and its unresolved hardware
limitations; those limitations still apply here.

## New in this build

- Board A stores an allowlist of notification apps. WhatsApp and WhatsApp
  Business are enabled initially. Other apps can be added after a fresh iPhone
  notification identifies them; only allowed apps have their notification text
  requested and forwarded. Each app can use a full preview, title/sender only,
  or app name only.
- The setup page shows Board A/B connection checks and can open pairing, start
  app discovery, change app choices, and request a Board B test notification.
  It speaks directly over USB; no account or configuration server is involved.
- The existing silent import of recent ANCS notifications remains available for
  allowed apps. This is not a chat archive and does not recover cleared items.

## Verification and limits

The host tests and both ESP32 builds pass with pinned ESP-IDF v5.5.5. These
exact Board A and B applications were flashed at `0x10000` on connected
development boards after their partition tables were compared. Both booted,
reported their expected versions and roles, and reported a working wired
board-to-board link. Board A also saved and read back a temporary preview
setting, then restored the WhatsApp full-preview default. Existing Bluetooth
pairings were not deliberately erased, but reconnection was not verified.

The iPhone notification, Tesla message, app discovery, and audio paths were
**not** tested end-to-end on this build. A board status check does not prove a
notification reached the Tesla or that call audio is clear in both directions.
The previously observed phonebook-download failure and unverified music/call
features remain open. Test with the car parked and keep the direct phone
option available.

The [manifest](../../dist/manifest.json) records the exact image versions,
hashes, flash addresses, and hardware-validation status. Install matching A
and B images from this release. Full-image flashing may erase Bluetooth
pairings and saved app choices; see the [setup guide](../SETUP.md).
