# DashBridge 0.5.1-alpha

This prerelease keeps the complete 0.5 architecture and functionality while
making the installation artifacts unambiguous. The complete flash images are
now named `phone-full.bin` and `car-full.bin`: “full” means bootloader,
partition table, and application in one file. It does not mean that the two
board roles are combined.

## What's new since 0.5.0-alpha

- Renamed `phone-merged.bin` to `phone-full.bin` and `car-merged.bin` to
  `car-full.bin` across packaging, integrity checks, browser installation,
  tests, and current documentation.
- Kept the separate Board A and Board B firmware roles, the typed DashLink v2
  control protocol, dedicated media transport, staged pairing, serialized
  reconnect behavior, and Setup GATT v1 iOS compatibility unchanged.
- Rebuilt both role-specific images from the current sources and pinned
  ESP-IDF v5.5.5 toolchain.

The [manifest](../../dist/manifest.json) records image sizes, source hashes,
flash addresses, and the pinned ESP-IDF revision. Install A and B from this
same release. Full images flash at `0x0` and may erase Bluetooth bonds and app
choices. Application-only images flash at `0x10000` only when the existing
partition layout is known to match.

## Verification and limits

Both images build with pinned ESP-IDF v5.5.5. Architecture, protocol, bounded
input, call/music audio, reconnect, build-scope, browser, installer-integrity,
and production SDP/configuration checks pass. The iOS Setup GATT v1 contract is
checked against both firmware and companion-app code.

These exact images have **not** been installed and tested end to end with an
iPhone and Tesla. The manifest therefore keeps `hardware_tested: false` for
both. Notification delivery, clear bidirectional call audio, music playback and
controls, phonebook/history sync, and sustained reconnect behavior still need a
parked-car test. Earlier phonebook pulls returned zero records; this release
must not be presented as fixing that until hardware proves it.

Use the [setup guide](../SETUP.md) and the
[parked-car checklist](../../README.md#parked-car-test-checklist). Keep the
existing direct-phone option until the bridge has been verified in your car.
